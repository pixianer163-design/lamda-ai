## 🎯 战略方向

> "训练未来主要云上做，弄好之后保存在 OSS"

### 核心原则
1. **云上训练** - 利用阿里云 GPU/TPU 资源

3. **边缘推理** - 本地加载 OSS 模型进行预测

## 📦 数据流向

### 训练流程（云上）
```
1. 原始数据 → 阿里云 MaxCompute（清洗/预处理）
2. 训练任务 → 阿里云 PAI/ECI（GPU 训练）
3. 模型产出 → OSS Bucket（版本化存储）
4. 训练日志 → OSS/SLS（归档分析）
```

### 推理流程（本地）
```
1. 每日 9:25 AM → 从 OSS 下载最新模型
2. 9:30 AM → 加载模型进行预测
3. 缓存机制 → 本地保留最近版本（离线可用）
4. 失败降级 → OSS 不可用时使用本地缓存
```

## 🔐 安全建议

1. **AccessKey 管理**
   - 使用 RAM 子账号（最小权限）
   - 定期轮换（90 天）
   - 不提交到 Git

2. **OSS 权限**
   - Bucket 私有读写
   - 禁止公共访问
   - 配置 Referer 白名单

3. **数据传输**
   - 使用 HTTPS
   - 启用传输加密
   - 敏感数据本地加密
